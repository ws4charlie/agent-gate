# 控制台

[English](../console.md)

控制台是给运行网关的人用的本地网页。它显示每个 Agent 在做什么、花了多少，可以改它们的限额，也可以用模板跑研究任务。

## 一眼看清所有 Agent

每个 Agent 一张卡片：今天花了多少、离每日预算还有多远，花费在模型、工具、付款之间怎么分，调用了多少次，其中多少次被拒绝、失败或拦截。小图显示最近 24 小时每小时的花费。卡片上方是几个总数，以及从链上读到的钱包 USDC 余额。

事件页按时间倒序列出所有不是正常成功的请求，并写明是哪条规则拒绝的。

## 不用命令行也能改限额

在卡片上可以改 Agent 的预算和白名单，也可以停掉它、再恢复。改动从它的下一个请求开始生效。控制台没有另一套规则，它写的就是网关本来就在执行的策略。

## 用模板跑任务

模板是可以反复用的任务，有点像 skill：一段系统提示词、一个模型、允许用的工具，再加两个预算，一个管单次运行，一个管每天。自带几个公开的研究模板，你也可以自己写，或者复制一个内置模板再改。

每个模板都以自己的 Agent 身份运行。每次模型调用、搜索和付款都带着这个 Agent 的 key 经过网关，所以预算就是普通的策略，花费显示在它自己的卡片上，运行也能像其他 Run 一样被停止。任务运行时可以看到每一步陆续出现；结束后可以读报告、工具原始结果和完整对话记录。

## 谁能用它

控制台只监听本机。它的接口还需要一个 key，key 就在控制台启动时打印的链接里。这样网页、或者在同一台机器上有 shell 的 Agent，都没法通过控制台给自己加预算。能读你文件的人仍然能找到这个 key，就像他们也能直接连数据库一样，所以安全边界是这台机器本身。
