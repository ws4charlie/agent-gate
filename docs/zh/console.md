# 控制台

[English](../console.md)

控制台是给运行网关的人用的本地网页。它显示每个 Agent 在做什么、花了多少，可以改它们的限额，也可以用你自己的 Agent 跑研究任务。

## 一眼看清所有 Agent

总览页显示所有 Agent 加起来的数字：今天和最近七天花了多少，从链上读到的钱包 USDC 余额，最近一天调用了多少次、其中多少次被拒绝、失败或拦截，以及钱花在了哪些模型和工具上。

Agent 页给每个 Agent 一张简短的卡片：今天的花费和每日预算，以及有没有出问题。点开一个 Agent，可以看它自己的花费、活动、每小时花费图，以及它被允许用什么。

每个数字都可以点。点某个 Agent 的错误数，事件页就会打开，并且已经按这个 Agent 和错误筛选好，一步就能从“有问题”看到具体是哪些请求。

## 不用命令行也能改限额

在 Agent 的页面上可以给它改名、改预算和白名单，也可以停掉它、再恢复。改名后它的 key 照样能用。改动从它的下一个请求开始生效。控制台没有另一套规则，它写的就是网关本来就在执行的策略。

## 用你自己的 Agent 跑研究任务

任务是可以反复用的研究工作：查什么、怎么查，以及由你的哪个 Agent 来做。自带三个公开任务。其中两个由 GPT Researcher 来做，它擅长读很多来源再汇总；关于 x402 的那个由 Claude Code 来做，它还能读代码，说出 AgentGate 该改什么。你可以新建任务，直接修改任何一个任务（内置任务改过之后可以恢复原样），也可以拖动列表排成自己想要的顺序。

控制台自己不做研究。它启动这个 Agent 的执行程序，也就是本机上一个持有该 Agent key 的小程序，并交给它一个运行编号。每次模型调用、搜索和付款都以这个 Agent 的身份经过网关，并带着运行编号，所以 Agent 自己的限额照样生效：单次任务预算限制每次运行，日预算限制每天，运行也能像其他 Run 一样被停止。执行程序从控制台只拿到这次运行的信息，拿不到控制台自己的任何密钥；Claude Code 用的是一个单独的空设置目录，你平时用的 Claude Code 不受任何影响。

运行时可以看到每一步陆续出现；结束后可以读报告、完整轨迹和日志。这些文件只存在这台电脑上，只有你的用户能读，不需要时可以删掉这次运行。

## 谁能用它

控制台只监听本机。它的接口还需要一个 key，key 就在控制台启动时打印的链接里。这样网页、或者在同一台机器上有 shell 的 Agent，都没法通过控制台给自己加预算。能读你文件的人仍然能找到这个 key，就像他们也能直接连数据库一样，所以安全边界是这台机器本身。
