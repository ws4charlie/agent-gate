# 局限

[English](../limits.md)

先把这个项目做不到的事说清楚，省得你踩坑才发现。

**它还没见过真实流量。** 对 OpenRouter 的线上测试才刚开始，还没有真实业务经过它，所以所有性能数字都来自受控环境。

**只支持测试网。** 钱包故意拒绝主网，也没有处理链重组。支付已在公开测试网上结算过，但规模还很小。

**只能跑一个进程。** 多个网关可以安全地共用账本，但紧急停止功能默认只有一个进程。

**筛查比较浅。** 它能挡住常见的注入攻击，挡不住认真的对手。详见[工具](tools.md)。

**你要保护好运行它的机器。** 谁控制了网关所在的机器，谁就拿到了供应商密钥和数据库。请把它放在可信网络里，并由代理来处理 TLS。

**它故意做得很小。** 没有后台界面、供应商自动切换、负载均衡，也没有多租户管理。
