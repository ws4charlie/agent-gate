# 遥测

[English](../telemetry.md)

网关处理的每一次模型调用和工具调用，都会变成一个 OpenTelemetry span，字段遵循标准的 GenAI 语义约定。任何 OpenTelemetry 后端都能直接把它当作审计证据读取，无需自定义解析。

## 记录什么

一次模型调用是一个以所请求模型命名的 span，一次工具调用是一个以工具命名的 span。每个 span 说明这是什么操作、由哪个提供方或工具服务器处理、由哪个智能体和账户发起、用了多少 token、花了多少钱，以及如何结束。被拒绝或失败的调用会带有错误类型和错误状态；上游给出的响应 id 也会保留。

标准里没有对应名称的信息，例如费用、策略决定和运行，放在 `agentgate.` 前缀下。其他工具协议请求（如列出工具）只生成一个普通 span，带同样的 `agentgate.` 信息。

## 绝不记录什么

提示词、回答、工具参数和工具结果永远不会出现在 span 里。span 只含名称、id、数量和状态。

## 如何开启

默认关闭，开销几乎为零。设置 `AG_OTEL_EXPORTER=stdout` 可把 span 打印出来，适合试用时查看。设置 `AG_OTEL_EXPORTER=otlp` 则通过 OTLP/HTTP 发送到采集器或服务商，目的地和凭据由标准的 `OTEL_EXPORTER_OTLP_*` 环境变量决定。
